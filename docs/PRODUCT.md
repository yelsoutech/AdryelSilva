# Product

## Visão Geral

Marketplace Intelligence é uma plataforma SaaS B2B de inteligência de dados para vendedores de marketplaces. O produto coleta, processa e normaliza dados de múltiplos marketplaces, fornecendo uma visão unificada para análise e tomada de decisão.

## Público-Alvo

Vendedores que operam em marketplaces (Mercado Livre, Shopee, Amazon e outros) e precisam de dados consolidados e estruturados.

## Proposta de Valor

- Integração com múltiplos marketplaces a partir de uma única plataforma
- Pipeline de dados automatizado: coleta, validação, normalização e armazenamento
- Arquitetura multi-tenant desde o primeiro dia
- Extensível para novos marketplaces sem alteração estrutural
